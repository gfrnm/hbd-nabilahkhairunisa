## Isi Website
- Foto utama Nabilah dengan background ulang tahun pink/cream (file terpisah: `nabilah-birthday-photo.jpg`)
- Foto pasangan Gufron & Nabilah di bagian undangan makan bareng dengan background resto dinner ulang tahun (file terpisah: `gufron-nabilah-dinner-photo.jpg`)
- Amplop pembuka + backsound MP3 pilihan Gufron (auto play saat amplop dibuka, loop terus, tanpa tombol musik)
- Auto scroll sinematik pelan yang tetap bisa disentuh/di-scroll manual
- Stiker Nailong transparan di sisi kiri (Gufron & Nabilah suka stiker Nailong)
- Tampilan selalu terang walau HP mode gelap, layout dioptimalkan untuk mobile Android & iPhone
- Animasi balon melayang & hujan confetti
- Hitung mundur live ke 5 Oktober 2026
- Doa & surat dari Gufron Muhaimin
- Fitur tiup lilin interaktif
- Undangan makan bareng:
  - Dijemput: 17.00 WIB
  - Makan di resto: 18.00 WIB
  - Selesai: 19.00 WIB
  - Tombol Simpan ke Google Calendar
- Dress code: Atasan Kemeja Putih, Bawahan Celana Cream

## Cara pakai di GitHub
1. Buat repository baru di github.com, misal `happy-birthday-nabilah`
2. Upload file `index.html` dan `README.md` ini ke repository tersebut
3. Aktifkan GitHub Pages: Settings > Pages > Source: Deploy from a branch > main / (root) > Save
4. Website live di `https://<username>.github.io/happy-birthday-nabilah/`

## Cara pakai di Replit
1. Buat Repl baru > Import from GitHub (tempel URL repo di atas), atau Upload file
2. Upload `index.html` ini
3. Klik **Run** — website langsung jalan

## Cara jalan lokal
Cukup buka file `index.html` di browser.
